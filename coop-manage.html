미결

  1. Start training 버튼은 상태만 Waiting to start로 바꾸고, 실제 학습 시작은 TRAVI가 콘솔에서 승인한다. 승인한 뒤 리더에게 가는 알림은 'Training started for SOC Threat Detection Coop. Round 1 is running.'(SOC Threat Detection Coop의 학습이 시작됐고 1라운드가 돌고 있다는 뜻)으로 둔다. 승인 화면은 만들지 않는다.
  2. 참여 요청과 멤버 관리를 이 페이지의 탭으로 둘지, Dashboard와 떨어진 별도 페이지로 뗄지는 엇갈린 발언이 있어 정하지 않았다. 지금 Join requests와 Members 탭 구조는 확정 전 시안이다.
  3. Coop leader 명칭은 팀이 정하기 전 임시 표기다. 칩은 Leader로 쓴다.
  4. 체크리스트 세 항목은 예시다. 리더가 무엇을 확인해야 학습을 시작할 수 있는지 정해야 한다.
  5. 탈퇴 요청을 리더가 승인하는지, 상태만 보는지 정하지 않았다. 지금은 빈 상태만 보여 준다.

가정

  1. Approve와 Decline은 화면의 상태 칩만 바꾸고 아무것도 보내지 않는다.
  2. 아직 학습 전이라 학습 라운드 표와 언러닝 모델 알림은 넣지 않았다. 정산 탭과 정산 구역은 졸전 데모에서 빠졌다.
  3. 데이터와 연산 설명은 요청을 보낸 Org C 행과 연산을 내는 Org D 행에 둔다.
  4. Edit Coop은 시안이라 비활성이다. 숫자는 예시이고 기준일은 Nov 20, 2026이다.
