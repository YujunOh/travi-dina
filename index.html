HOW DISTRIBUTED LEARNING WORKS

Many ways to learn together,
each on your own data.

Distributed learning trains one model across members, and each member trains on its own data. Methods differ in what crosses the network. TRAVI runs on TL++ and is not locked to a single method.

METHOD A

Federated Learning

Each member trains a copy of the model on its own data. Only model updates go to a server, which averages them into a new global model, round after round.

Moves
Model updates (weights or gradients)
Fits
Neural networks, linear models
METHOD B

Federated tree ensembles

Random forests and gradient-boosted trees can be built across members. Each site grows trees on its own data, or shares split statistics, and the results are combined into one ensemble.

Moves
Trees or split statistics
Fits
Tabular data, Random Forest, XGBoost
METHOD C

Traversal Learning (TL++)

The model visits members in turn. Only cut-layer activations and gradients move, and virtual batches give the same gradient updates as centralized training on the same batch. Intermediate values are computed with multi-party computation.

Moves
Cut-layer signals only
Fits
Deep neural networks
TL++

Value alignment RESEARCH

TL++ is designed to check each sample against a member's own values, so only data that fits enters training. Similar members group into cohorts that build a shared model.

TL++

Transparent attribution RESEARCH

TL++ is designed to trace each sample's effect on the model, so points can follow contribution.

How a Coop works

Every Coop moves through the same five stages.

01

Create

A Coop leader sets the goal, the model, and the roles to fill.

02

Recruit

Others choose a role and request to join. The Coop leader approves each request.

03

Train

Members train one shared model. Each member trains on its own machines.

04

Evaluate

The model is evaluated, and each member's contribution is scored.

05

Reward

Members earn points based on their contribution.
