미결

  1. 로그인을 Google 하나에 기대는 것에 대한 우려가 있었다. 다른 소셜 로그인을 더할지, 이메일 자체 로그인을 언제 열지는 교수님 확인 전이다.
  2. 이메일과 비밀번호 칸을 숨길지 비활성으로 보여 줄지 정하지 않았다. 지금은 비활성으로 보여 주고 나중에 열린다는 안내를 단다.

가정

  1. 로그인 페이지는 가입(join.html)과 나눴다. Google 우선이고 자체 로그인은 나중 백엔드에서 붙인다.
  2. 비로그인 상태에서 코옵 상세의 Request to join을 누르면 이 화면으로 온다(login.html?coop=soc&return=request.html%3Fcoop%3Dsoc). 출처 배너는 상세 페이지 게스트 도움말 'Log in to send a join request. You'll return to this Coop afterward.'(로그인하면 참여 요청을 보낼 수 있고 로그인 뒤 이 코옵으로 돌아온다는 뜻)와 같은 틀로 썼다.
  3. 시안에서는 Continue with Google을 누르면 바로 회원 상태가 되어 주소의 return 값으로 간다. return이 없으면 Dashboard로, 코옵에서 왔으면 참여 요청 페이지로 간다.
  4. Google 로그인 실패 상태는 login.html?error=1로 본다.
